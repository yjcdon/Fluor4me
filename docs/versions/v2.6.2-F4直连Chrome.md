# Fluor4me 2.6.2 · F4 直连 Chrome

发布于 2026-11-25。

## S · 背景

上一版通过启动 Chrome 转发进程来打开新标签页，按键到打开结果之间多了一段进程启动。浏览器忙时连续触发，也容易积累待处理请求。

## T · 目标

缩短 F4 打开结果的路径，确保一次只处理一个请求。忙时的连按应被忽略，浏览器恢复后可以继续正常触发。

## A · 做法

- 在浏览器支持直接打开的场景，通过本地连接把请求交给正在运行的 Chrome 实例，并核对接收进程。
- 等浏览器响应或关闭连接后再接受下一次请求，期间忽略连按。保留默认搜索引擎、无痕窗口归属和来源地址栏回退路径。

## R · 结果

发行包在 macOS 27.2.1 验证了解包启动。同一构建在 Chrome 158 的普通和无痕窗口各进行了三次模拟按键测试，按键到新标签页出现用时 60–82 毫秒，计时止于标签页出现。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.6.2)

# Fluor4me 2.6.0 · 重做原生菜单与设置

发布于 2026-11-19。

## S · 背景

设置、规则和运行中的应用是日常管理功能键的入口。项目仍依赖旧的界面和构建流程，窗口操作、语言切换和登录启动分散在不同位置。

## T · 目标

让三个窗口遵循 macOS 常用操作，切换语言时保留当前编辑状态，并让 Apple 芯片 Mac 用 Command Line Tools 即可从源码构建。

## A · 做法

- 用 Swift 和 AppKit 创建菜单、设置、规则与运行应用窗口，支持最小化和 ⌘W。
- 把语言和登录启动放到「设置 → 通用」，把版本、署名和项目入口放到「关于」。
- 移除应用内更新弹窗、模式切换通知和启动时自动搬移应用的逻辑。用构建脚本生成和签名 app，发行目标为 arm64 和 macOS 14.0。

## R · 结果

简体中文与英文可在运行时切换，打开的窗口保留搜索、筛选和当前设置标签。在 macOS 27.2.1 验证了解包启动。安装到个人「应用程序」目录后，拖出图标可立即隐藏，从系统设置可立即恢复。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.6.0)

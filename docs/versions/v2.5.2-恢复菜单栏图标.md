# Fluor4me 2.5.2 · 恢复菜单栏图标

发布于 2026-11-17。

## S · 背景

在 macOS 27 上，Fluor4me 图标被拖出菜单栏后，需要能从系统设置重新显示。菜单栏是进入设置和键盘规则的主要入口，找回图标也涉及已有配置的保留。

## T · 目标

让系统接管菜单栏图标的显示和隐藏。升级后可从原有规则继续使用，图标恢复时应用无需重启。

## A · 做法

- 用新的应用标识 `io.github.yjcdon.Fluor4me` 重新注册菜单栏入口。
- 首次启动时从旧应用标识导入缺失的键盘规则与偏好。菜单栏显示状态由系统重新登记，辅助功能权限在新版中重新授予。
- 在 macOS 27 使用系统的菜单栏显示开关，在旧系统保留原有入口处理。

## R · 结果

在 Apple 芯片 Mac 的 macOS 27.2.1 上验证了解包启动和菜单栏操作。按住 ⌘ 拖走图标后，可从「系统设置 → 菜单栏」恢复显示。该版 arm64 可执行文件最低目标仍为 macOS 11.0。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.5.2)

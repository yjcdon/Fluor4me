# Fluor4me 2.6.1 · F4 访问网址和搜索

发布于 2026-11-24。

## S · 背景

早期 F4 会把选区交给 Google 搜索。选中的内容也可能是网址，用户也可能为当前 Chrome 配置选了其他搜索引擎，或者在无痕窗口中操作。

## T · 目标

用同一个 F4 快捷键直接访问选中的网址，或用当前 Chrome 配置的默认引擎搜索文字。无痕操作的结果留在发起操作的窗口。

## A · 做法

- 从网页选区区分完整网址、裸域名和普通文字。网址直接打开，文字交给 Chrome 按当前配置搜索。
- 普通窗口和可确认目标的单配置无痕窗口直接打开新标签页。目标不明确时，通过来源窗口的地址栏提交。

## R · 结果

发行包在 macOS 27.2.1 验证了解包启动。发行记录覆盖普通窗口搜索，以及无痕窗口访问网址和搜索。直接打开时源地址栏无需获得焦点。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.6.1)

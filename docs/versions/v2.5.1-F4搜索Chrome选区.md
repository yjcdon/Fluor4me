# Fluor4me 2.5.1 · F4 搜索 Chrome 选区

发布于 2026-11-17。

## S · 背景

原版 Fluor 可以按应用切换功能键模式。在 Chrome 里搜索网页选区，仍需要先选中文字，再用右键菜单或地址栏提交。Fluor4me 需要把这一步融进现有的键盘操作。

## T · 目标

在 Chrome 前台时，用受支持的 Mac 内置键盘按 F4，在新标签页搜索选区。Chrome 的亮度和音量键照常使用，切出 Chrome 后恢复下一个应用的键盘模式。

## A · 做法

- 通过 macOS 辅助功能读取 Chrome 网页选区，将文字编码后提交给 Google 搜索。
- 在 Chrome 前台临时映射 F4，并使用媒体键模式。随前台应用切换应用相应规则。
- 移除启动时获取上游发行说明的步骤，发布供 Apple 芯片 Mac 安装的 ZIP。

## R · 结果

发布了 arm64 ZIP。发行记录注明，可执行文件最低目标为 macOS 11.0，启动与操作流程检查在 macOS 27.2.1 完成。跨段选区的段落分隔取决于 Chrome 辅助功能接口的返回内容。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.5.1)

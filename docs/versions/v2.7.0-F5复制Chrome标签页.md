# Fluor4me 2.7.0 · F5 复制 Chrome 标签页

发布于 2026-11-25。

## S · 背景

浏览时有时需要保留当前页，再用一张副本往回查看前一页。手动复制网址只能重新打开页面，浏览历史要借助 Chrome 的原生复制命令保留。

## T · 目标

在受支持的 Mac 内置键盘上按 F5，把当前标签复制到同一个普通或无痕窗口，并保留浏览历史。长按时只生成一张副本。

## A · 做法

- 复用 F4 的前台应用判断、临时键盘映射和退出清理，离开 Chrome 后撤销应用设置的映射。
- 通过 macOS 辅助功能调用 Chrome 原生的「复制标签」，支持英文、简体中文和繁体中文菜单。
- 忽略按住按键时系统送来的重复事件，直接执行复制命令，地址栏无需获得焦点。

## R · 结果

发行包在 macOS 27.2.1 验证了解包启动。同构建号在 Chrome 158 的普通和无痕窗口做过模拟按键验证，副本留在原窗口并保留浏览历史。 [GitHub Release](https://github.com/yjcdon/Fluor4me/releases/tag/v2.7.0)

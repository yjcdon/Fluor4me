# 键盘状态恢复

整排功能键模式与单键 HID 映射分别核对。开始前记录系统模式以及内置键盘原有映射。用实际按键验证模式，有可用的只读 HID 查询工具时同时记录映射差异。

## STATE-01 在 Chrome 暂停后恢复

- **前提**。启动前设为标准功能键，当前 Chrome 前台，F4、F5 均可用。
- **步骤**。从菜单栏勾选「禁用」并回到 Chrome，核对 F4、F5 和系统模式。在 Fn 按键切换模式下，暂停期间短按 Fn 再恢复。另测暂停期间按下 Fn、恢复后放开。
- **预期**。暂停恢复启动时的整排模式，移除本应用的两条临时映射，已有映射保留。暂停期间的 Fn 不修改偏好，恢复时按当前应用重新应用规则，Chrome 两项快捷操作重新生效。

## STATE-02 正常退出按设置恢复模式

- **前提**。Chrome 前台且两键已经生效。由菜单操作正常退出。
- **步骤**。从启动时设为标准功能键、Chrome 中生效为媒体键的基线，分别测试「退出时重置模式」关闭、开启并选择「恢复启动时的模式」。另用媒体键作为启动模式，开启退出重置并指定功能键。每次启动后重新进入 Chrome 验证再退出。
- **预期**。三次结果分别为媒体键、启动时的功能键、指定的功能键。每次退出都移除本应用的两条临时映射，原有映射保留。指定模式控件只在对应设置下出现，切走再切回后保留所选值。

## STATE-03 强退后启动清理残留

- **前提**。使用可恢复的授权测试环境，记录原有映射。确认两项快捷操作均可用。
- **步骤**。Chrome 前台时强退测试实例。先将另一个有规则的应用置前，再重启候选版。比较原映射和重启后映射。切回 Chrome 对两项快捷键分别测试一次。
- **预期**。重启清理本应用残留的 F4 和 F5 映射，保留已有映射，当前应用规则生效。重新进入 Chrome 后每个快捷键仅触发一次。

## STATE-04 休眠唤醒后仍可切换

- **前提**。获准让测试 Mac 真实休眠。Chrome 和另一个具有不同规则的应用均已准备好。
- **步骤**。Chrome 前台时让 Mac 休眠并唤醒解锁。切入另一个应用验证其功能键，再切回 Chrome 分别验证 F4、F5。再走一轮。
- **预期**。每轮都恢复当前应用模式。Chrome 的 F4 和 F5 每次各新增一个正确的标签，切走后两条临时映射移除。

## STATE-05 已有键盘映射冲突时保留原值

- **前提**。使用有既有映射样本的隔离环境。分别准备无关映射和占用 F4 或 F5 来源键的映射，保存可恢复的基线。
- **步骤**。每种情况下进入 Chrome，分别测试 F4 和 F5，离开 Chrome 并正常退出后比较内置键盘的映射。冲突可用两个独立样本分别覆盖两键。
- **预期**。无关映射与两项快捷键同时工作。单键冲突时已有映射优先，另一快捷键仍可用。退出后原有映射保持不变。

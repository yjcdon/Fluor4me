# 安装和升级

## INSTALL-01 候选包启动与最低系统验收

- **前提**。使用 `PKG-01` 检查过的 Release 包。最低系统分支使用 macOS 14.x 的 Apple Silicon Mac 真机，Chrome 用例需要受支持的内置键盘。
- **步骤**。在测试账户解压 ZIP，从「下载」目录启动，核对进程路径和菜单栏。退出并手动移到个人「应用程序」目录，再次打开。在 macOS 14.x 实测 `KEY-01`、`CHR-01`、`CHR-04` 和 `STATE-01`。已完成的相同构建及环境结果可以引用。
- **预期**。两次均从选定路径启动，菜单栏可操作。安装位置由用户控制，没有应用发起的搬移提示、自动复制或重启。最低系统分支以实际按键及窗口结果为准，有通过记录再确认实机兼容性。

## INSTALL-02 从旧版升级后保留配置

- **前提**。使用授权的隔离账户。以旧版（例如 `v2.5.2`）建立两条不同的应用规则，记录默认模式、切换方式和退出选项。有旧偏好域样本时，另用 `com.yjcdon.Fluor4me` 验证迁移路径。
- **步骤**。正常退出旧版，启动候选版，检查规则、设置及实际按键。修改一条规则并再次启动。验证旧偏好域时，在新偏好域留一个已知值作对照，区分应沿用的现有值和应补入的旧值。
- **预期**。旧规则和设置继续生效，修改后可持久化。不同偏好域之间只补入当前缺失的有效设置，现有值与后续修改保留。若系统要求重新授予辅助功能，授权后可按 `CHR-06` 验证快捷键。

## INSTALL-03 启用和关闭登录时启动

- **前提**。候选版位于个人「应用程序」目录，使用已获准重新登录的测试账户。
- **步骤**。打开「设置 → 通用」勾选「登录时启动 Fluor4me」。如系统要求批准，在系统设置批准，返回核对勾选。重新登录，观察菜单栏并按 `KEY-01` 验证切换。取消勾选，再重新登录一次。
- **预期**。批准后开关同步为已启用，登录后应用自动启动并管理键盘。关闭后下一次登录时不启动。清理时恢复测试前的登录启动状态。

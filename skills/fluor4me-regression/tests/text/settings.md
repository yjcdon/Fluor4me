# 菜单和设置

## UI-01 设置、关于和首次打开

- **前提**。使用干净的测试账户和已确认版本的候选包。首次打开的辅助功能授权按 `CHR-06` 记录。
- **步骤**。启动并打开「设置」，查看通用、高级、关于三个标签。切换浅色和深色外观，检查关于页的图标、版本、署名和 GitHub 入口。重开设置，核对窗口位置。操作涉及打开链接时，在获准后核对最终仓库地址。
- **预期**。设置控件完整，切换标签保留窗口标题，重开时保留位置。关于页显示发布版本和署名，GitHub 图标能打开 Fluor4me 仓库。首次打开和切换模式均无应用发起的更新、通知授权或模式通知。

## UI-02 从菜单打开窗口、最小化与关闭

- **前提**。准备一个可搜索的应用及对应规则。
- **步骤**。从菜单打开规则、设置和运行中的应用，分别选定设置标签或输入搜索词。逐个最小化，再从原菜单项恢复。并排打开两个窗口，把规则窗口的搜索框置前，按 ⌘W，再测试另外两个窗口。
- **预期**。窗口恢复后保留选中的标签和搜索词。每次 ⌘W 只关闭前台窗口，菜单栏和应用进程仍可用。三个入口均可重新打开。

## UI-03 中英文即时切换与偏好保留

- **前提**。设置、规则、运行中的应用窗口已打开。列表中有搜索词、选择和筛选状态。
- **步骤**。在「设置 → 通用」先切英文，再切简体中文。两次检查菜单、窗口标题、设置标签和列表。正常退出后再次打开。
- **预期**。打开的界面即时换语言，搜索词、规则选择、筛选和所选设置标签保留。重启恢复上次选择，系统语言和键盘偏好保持原值。

## UI-04 菜单栏模式图标和系统显示开关

- **前提**。有可触发两种功能键模式的规则。系统显示开关分支使用 macOS 27、已放入个人「应用程序」目录的候选版。
- **步骤**。分别在浅色和深色外观切换媒体键、功能键、禁用状态，检查菜单栏。再在 macOS 27 按住 ⌘ 将图标拖出菜单栏，实际切换应用并试键。打开「系统设置 → 菜单栏」重新显示 Fluor4me。
- **预期**。三种图标均可辨认，和实际生效模式一致。系统隐藏图标后规则与 Chrome 快捷操作继续工作。重新显示后，菜单立即可用并反映当时状态。

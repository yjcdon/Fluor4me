# Chrome 快捷键

从 [Chrome 测试样本](../../references/chrome-samples.md)选择真实网页或本地对照页，获准后在对应窗口的新测试标签页打开。F4 核对实际选区、目标地址和标签数量，F5 用同一标签页建立后退记录。失败时记录按键前后的窗口、焦点和标签数。

## CHR-01 普通窗口 F4 访问网址和搜索

- **前提**。辅助功能已授权，使用受支持的内置键盘。Chrome 从默认数据目录启动，普通窗口在前台，其默认搜索引擎已知，优先选有非 Google 搜索引擎的测试配置。为 Chrome 保存一条标准功能键规则。
- **步骤**。分别选中样本的裸域名、带查询参数的网址和 `C++ 测试`，逐次单按 F4，每次返回样本后再测下一条。核对原窗口标签数、目标和地址栏焦点。前台仍为 Chrome 时验证亮度和音量，再切回另一个有规则的应用。
- **预期**。每次增加一个结果标签。裸域名和完整网址直接访问相应地址，路径和查询参数完整。搜索使用当前配置的引擎，搜索词保留加号和中文。普通窗口直达分支中，源标签页的地址栏不获得焦点。Chrome 的亮度、音量正常，保存的规则保持原值，切回其他应用时其规则生效。

## CHR-02 F4 无痕窗口与回退路径

- **前提**。辅助功能已授权，同开普通窗口和无痕窗口。分别准备可确认的单配置环境，以及无法确认目标的测试环境，例如多个 Chrome 配置的专用账户。
- **步骤**。在每种环境中，从无痕样本页依次对网址和搜索词按 F4。记录源窗口、各窗口的标签数、当前配置的搜索引擎和结果位置。可看见地址栏短暂获得焦点时，记录为回退路径的证据。
- **预期**。结果始终留在发起操作的无痕窗口，普通窗口不增加标签。单配置且满足直达条件时源地址栏不获得焦点。无法确认目标时可通过源窗口地址栏提交一次，仍使用该窗口的搜索配置。

## CHR-03 F4 忽略无效或非网页选区

- **前提**。从 `CHR-01` 确认当前环境的 F4 可用。密码框使用样本的虚构值。
- **步骤**。逐项测试网页未选择文字、纯空白选区、Chrome 地址栏选区以及聚焦并选中密码框内容。每种状态按一次 F4。最后在样本普通文本输入框内选中 `C++ 测试` 复测。
- **预期**。四个负例均新增零个标签页。普通网页输入框中的选区可搜索，并新增一个结果标签。

## CHR-04 F5 复制当前标签页并保留历史

- **前提**。辅助功能已授权。同开普通和无痕窗口，各自用样本建立一条后退记录。
- **完整覆盖**。Chrome 菜单语言与窗口模式共 6 种组合。

  | Chrome 菜单语言 | 普通窗口 | 无痕窗口 |
  | --- | --- | --- |
  | 英文 | 英文普通窗口 | 英文无痕窗口 |
  | 简体中文 | 简体中文普通窗口 | 简体中文无痕窗口 |
  | 繁体中文 | 繁体中文普通窗口 | 繁体中文无痕窗口 |

- **步骤**。逐个执行上表组合，从样本第二页单按 F5，核对副本地址和所在窗口。在副本按后退，检查回到样本第一页且源标签仍停在第二页。地址栏在操作开始前保持未聚焦。切回其他应用检查按键。
- **预期**。每次仅新增一个副本，留在源窗口，与 Chrome 原生「复制标签」结果一致。副本保留历史，源标签不变，地址栏未获得焦点。离开 Chrome 后 F5 由当前应用的键盘模式处理。

## CHR-05 Chrome 忙时连按及按住 F4、F5

- **前提**。F4 和 F5 均已通过正例，测试页有可选内容。忙时分支须能观察到第一条请求仍在处理，可用隔离环境的调试暂停或可靠的慢响应样本。
- **步骤**。分别长按一次 F4 和 F5，每次松开后核对新增数量。再在能确认首条请求尚未完成时连按 F4、F5。响应恢复后重新使用两种快捷键各一次。
- **预期**。一次长按只新增一个结果或副本。忙时连按不排队补开标签，恢复后新按键仍可正常执行。无法确认首个请求处于忙时则单独记录该分支未验证。

## CHR-06 辅助功能拒绝后重新授权

- **前提**。使用隔离测试账户和受支持的内置键盘，候选包暂未获辅助功能权限。
- **步骤**。首次打开时暂缓授权，使用默认的自动切换方式，按 `KEY-01` 验证 A、B 的实际按键，并查看菜单的权限入口。再在 Chrome 分别用有效选区和有历史的标签测试 F4、F5。通过菜单的「请求权限」进入授权流程，在系统设置授予权限，切走并切回 Chrome，复测两键。最后选一种 Fn 切换方式并验证短按。
- **预期**。未授权时自动规则仍生效，菜单可请求权限，F4、F5 均不新增标签页。授权后能选择 Fn 切换方式，两项 Chrome 快捷操作和 Fn 均可用。

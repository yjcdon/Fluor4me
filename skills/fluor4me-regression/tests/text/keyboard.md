# 逐应用功能键

## KEY-01 自动切换和规则持久化

- **前提**。选随活动应用切换。默认设为媒体键，选两个可切换的非 Chrome 应用 A 和 B。可用「终端」和「文本编辑」。
- **步骤**。在规则编辑器用「添加规则」选中 A 的应用包，将 A 设为功能键。B 不建规则，跟随默认模式。交替置前并按同一个顶排按键。正常退出并重开 Fluor4me，检查保存的规则和实际按键。删除 A 的规则，再按一次。
- **预期**。A 收到标准功能键，B 执行相应的亮度或音量调整。重启后行为一致。删除规则后 A 跟随默认。可用 `cat -v` 观察终端转义序列，按 Ctrl+C 结束。

## KEY-02 多处编辑同一条规则

- **前提**。运行 A，确保菜单栏的「当前应用」显示 A。
- **步骤**。用「运行中的应用」搜索 A 并选功能键，再从「当前应用」改成媒体键。到规则编辑器核对后改回功能键。切换「显示全部」，再搜索 A。
- **预期**。三个入口显示最新模式。筛选仅改变展示，与 A 无关的规则保持原值。在规则编辑器只保留一条 A 的规则。

## KEY-03 Fn 切换当前应用和默认模式

- **前提**。测试副本已有辅助功能权限。A 和 B 可切换。默认模式设媒体键，A 跟随默认。
- **步骤**。选择「通过按 fn 键为活动的应用切换模式」。在 A 短按 Fn 三次，每次松开后核对规则和实际按键，并切入 B 作对照。切换成「通过按 fn 键切换默认模式」，短按一次，再分别尝试长按和按住 Fn 时按其他键。
- **预期**。A 依次采用另一种模式、默认对应的显式模式、跟随默认，B 的规则不变。全局模式下短按改变默认模式，长按及组合键保持配置原值。
